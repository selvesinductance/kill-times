# FREEZE BREAK

約20秒のモーショングラフィックスが要所で「凍結」し、止まった物体の形から操作（押す・引いて放す・滑らせる・切る・回す・連打）を読み取ってジェスチャで解くと、時間が一気に動き出すゲーム。
three.js（r128）の3Dで描き、WebGL が使えない環境では 2D の代替表示で最後まで遊べる。1枚の HTML で動く。

## ビルド

```
python3 build.py
```

- `src/*.js` をファイル名の番号順に連結して1つの即時関数（`'use strict'`）にまとめ、`src/template.html` の `//__SCRIPT__` に差し込む。
- 出力
  - `dist/freeze-break.html` … 公開用（アーティファクトの本文。`<!DOCTYPE>`・`<head>`・`<body>` の外枠は公開時に付く）
  - `dist/preview.html` … 手元の確認用（外枠つき。ブラウザで直接開ける）
  - `build/bundle.js` … 連結した JS（検査用）
- Node.js があれば連結後の JS を `node --check` で構文確認する。
- three.js は cdnjs から読み込む（オフラインでは 2D の代替表示になる）。

## URL の検証用パラメータ

| パラメータ | 内容 |
|---|---|
| `?debug` | 情報表示とスクラブバー（H キーで時間を止める） |
| `?t=秒` | その時刻から始める（例 `?t=6.3`） |
| `?hold` | 時間を止めたまま表示する（`?t=` と組み合わせて静止画を確かめる） |
| `?auto` | 各ゲートを自動で成功させて最後まで通す |
| `?flat` | WebGL を使わず 2D の代替表示で動かす |

M キーで音の入り切り。検証スクリプト向けに `window.__fb`（状態・ゲートの操作手順・3Dの場面の指紋など）を公開している（`src/80_debug.js`）。

## 確かめ方（ヘッドレス Chromium・Playwright）

先に `python3 build.py` でビルドしてから。

```
python3 tools/check.py --no-shots      # 通しの検証（下記）。--shots title,1.5,3.0 で指定時刻のスクショを shots/ へ
python3 tools/regress.py check         # 見え方の回帰検査（基準 tools/regress_base.json と比べる）
python3 tools/regress.py save          # 今のビルドを新しい基準にする（見た目を意図して変えたとき）
python3 tools/shots.py shots/after     # 比較用スクショ（20 時刻）。--pair shots/base shots/after で左右に並べる
```

- `check.py`: ?auto で結果画面まで通るか・もう一度ボタンで再開するか、実際のクリック・ドラッグで G1〜G5 を解けるか（タップだけでは進まないか）、コンソールエラーが 0 か。
- `regress.py`: 90 の時刻（`?hold&t=`）で3Dの場面の全ての物の見え方・位置・向き・大きさ・材質を記録し、3D区間 A〜F のカメラの道も 51 点ずつ比べる。粒・音のスペクトル・実時間で回る背景の図形の向きは乱数・音・時刻で変わるので比べない。リファクタリングで見た目が変わっていないことの確認に使う。

書式は prettier 3（設定 `.prettierrc`）。静的検査は連結後の `build/bundle.js` に ESLint（未使用の変数・未定義の名前・重複したキーと case）。

### 流れ

| 区間 | 時刻 | 内容 | 終わりのゲート |
|---|---|---|---|
| T タイトル | 0.0 | 押しボタン | G0 押す |
| A 点火 | 0.0–3.0 | 光点が飛び、パチンコが組み上がる | G1 引いて放す |
| B 飛翔 | 3.0–6.5 | 輪をくぐる。門が組み上がり、扉が玉を検知して閉まる | G2 滑らせる |
| C 落下 | 6.5–10.0 | 扉が開き、縦穴を落ちる。縄の部屋 | G3 切る |
| D 衝撃 | 10.0–13.5 | 重りが落ちて床が砕け、機械室へ。大ダイヤル | G4 回す |
| E 充填 | 13.5–17.0 | 回路を光が走り、渦を巻いて集まってコアになる | G5 連打 |
| F 解放 | 17.0–20.0 | コアが破裂。虹色の空と花火、ロゴと CLEAR | → 結果 |

### しくみの要点

- **状態機械**（`Game.phase`）: `PLAY`（時間が進む）→ 区間の終わりで `GATE`（凍結して操作を待つ）→ 成功で `BURST`（ヒットストップ。コアは溜めてから放つ）→ 次の区間の `PLAY`。最後は `RESULT`。凍結の手前では時間と BGM が一緒に減速し（`CONFIG.windDown`）、凍結明けはゆっくりから加速する（`CONFIG.resume`）。
- **区間の定義**（`defineStage(id, def)`）: `draw`（2D の代替表示）、`camera`（2D カメラ）、`events`（区間内の時刻 u を通ったら呼ぶ）、`gate`（ゲートの位置と見た目）、`three`（3D）。`three` は `build(scene)`・`update(u, o)`・`camera(u)`・`plane`（ゲートを置く平面）・`overlay(ctx, u)`（平面に沿って描く2D）を持つ。3D の物は区間ごとの `THREE.Group` に入り、今の区間だけ見せる（前後の区間の物を `update` で見せることはある）。
- **ゲート平面**: 3D の区間では、ゲートの 2D 座標を 3D の平面へ写し（`World3D.setPlane`）、手前の 2D キャンバスにも同じ変換で操作対象・粒・ヒントを描く。入力も同じ平面の座標に戻す。
- **粒**: 3D の区間では粒をすべて 3D のきらめく粒（虹色に移ろい瞬く十字）で描く。凍結中の操作への反応だけは 2D（実時間で動く）。
- **音**: 効果音と BGM は WebAudio でその場で合成する。BGM の刻みはゲームの時計に固定し、出力の遅れぶん早く鳴らす。拍（`Beat`）は区間の経過時間から求め、映像の脈動と背景の演出に使う。
- **やり直し**: 後の区間が前の区間の物を動かすので、組み上げた直後の姿を覚えておき（`World3D.snapshot`）、やり直すときに戻す（`World3D.restore`）。

## リファクタリングで変えたこと（2026-09-27）

見た目と動きは変えていない（`regress.py` で 90 時刻の3Dの場面とカメラの道が完全一致、`check.py` 全OK、2D の代替表示も完走）。
