# デザイン・UI のこだわり

指スマのゲーム制作の中で、Claude が指示なしに作ったものから直してもらった点をまとめたものです。
次の制作でも最初からこの方針で作るための覚え書きです。
「指示なしの場合」は、今回 Claude が最初にそうしていた（またはしがちな）こと、「こだわり」は直したあとの方針です。

---

## 1. 進め方

| 指示なしの場合 | こだわり |
|---|---|
| 依頼を受けたらすぐ作り始める | 大きなものは、作る前に確認したいことを**選択肢形式**で聞く |
| 気づいた変更はすぐ公開中のページに反映する | 遊んでいる人がいる間は勝手に更新しない。更新すると何が起きるか（遊んでいる途中の人が追い出されるか）を先に説明する |
| 部分の修正のついでに、近くの部品も揃えて直す | **頼まれた部分だけ**を変える（例：「好きな色」だけ直す依頼では、色の見本の形も位置も変えない） |
| 数値は Claude が決めて終わり | 角丸・文字の太さなどは、何段階か試して決めることがある。**一か所で変えられる形**（共通の変数など）にしておく |
| 軽くするために形や画質を落とす | **品質は落とさない**。軽くするなら、計算済みのデータを使うなど別の方法を取る |

## 2. 全体の見た目

| 指示なしの場合 | こだわり |
|---|---|
| デフォルメした手、ちゃぶ台などの土台 | **リアルな形**の手袋をはめた手。テーブルは置かず、**空中に浮かせる** |
| 背景にも文字や模様を描き込む（黒板の文字など） | 背景は**情報を持たせない**（黒板は無地）。全体を**ぼかして**主役（手）だけをくっきり見せる |
| 表面に質感（編み目・リブ）や飾り（縫い目）を付ける | 表面は**凹凸のないなめらかな**質感。飾りの縫い目は付けない |
| 部品を組み合わせた形（境目が見える） | 本物のように、**部品の境目が見えない**形にする |

## 3. 文字・言葉

| 指示なしの場合 | こだわり |
|---|---|
| 結果に説明を添える（例：「立った親指は合計2本 → はずれ」） | 結果は**一言だけ**（「はずれ」「当たり！」）。数は別の場所（中央の数字）で見せる |
| 見れば分かる表示にも説明文を足す（例：「薄い数は、合計になり得ない数です」） | **見て分かる表示に説明文は付けない** |
| ボタンの中にも見出しと同じ言葉を入れる（各ボタンに「1番目」） | 共通の言葉は**列の見出しに一度だけ**（「1番手〜4番手」を上に書き、ボタンの中は省く） |
| 情報欄にいろいろ載せる（例：「ラウンド1・宣言者・場の手○本」） | 必要最小限（「ラウンド 1 ・ 宣言者 NPC2」だけ） |
| 対戦の記録（ログ）を画面に出す | 対戦中の**ログは出さない** |
| 日本語の改行はブラウザ任せ（言葉の途中で切れる） | **文節の切れ目でだけ改行**する。Safari を含むどのブラウザでも効く方法にする |
| AI（NPC）の不自然に見える行動をそのままにする | 理由がある行動は**ひとこと添えて**分かるようにする（「はずれ（戦略のうち）」） |
| ルールを Claude が書く | ルールは「基本のルール」と「さらに今回は…（特別ルール）」に**分けて箇条書き**。大事な点は**太字**で強調 |

## 4. フォント

| 指示なしの場合 | こだわり |
|---|---|
| 個性の強い見出し用フォント（Dela Gothic One） | 見出しは**角の丸い太字**（M PLUS Rounded 1c） |
| 本文はいろいろなフォント（Zen Kaku Gothic New など） | 本文は **Noto Sans JP** |
| 太さを細かく使い分ける（400・500・700・800・900） | 太さは **400・700・900** の3つに整理。読み込む太さも減らす |
| 補助の小さいラベルも太字 | 数値を引き立てるため、補助のラベル（「目安」など）は**細く（400）** |

## 5. 色

| 指示なしの場合 | こだわり |
|---|---|
| ボタンは全部同じ色 | 値（難しさの目安）に合わせて**色を変える**：小さいほど**赤**、大きいほど**緑**。明るさも値に合わせて変え、色の見分けが苦手な人にも順番が分かるようにする |
| 色の意味を示す帯（凡例）を付ける | 数値がボタンに書いてあるので、**凡例は付けない** |
| 強調色をタイトルの装飾全体に使う | 強調色（赤）は**大事な言葉だけ**（「下げられない」） |
| 達成しても見た目は変わらない | 全部達成したら、タイトルが**ゲーミング色（虹色が流れて光る）**になるご褒美 |
| マウスを乗せてもカーソルが変わるだけ | 操作できる 3D の物には、マウスを乗せると**黄色い輪郭**を付ける |

## 6. 形（角丸）

| 指示なしの場合 | こだわり |
|---|---|
| 部品ごとにばらばらの角丸（22・20・16・14・12・10・8px、名札は完全な丸） | **3段階に統一**：窓・パネル **16px**、ボタン **12px**、小さい部品 **6px**（名札・札・情報欄・入力欄も含む） |
| ― | 色の見本（プリセット）は**丸のまま**。カスタム色だけ正方形（「好きな色 [■]」の順） |

## 7. 配置・操作

| 指示なしの場合 | こだわり |
|---|---|
| 操作はパネルのボタンだけ | 画面の中の物（自分の手）を**直接クリック・タップ**しても操作できる |
| 操作パネルは画面の端に1つ | PC の横長画面では、**操作する物のすぐ近く**（手の下）にもボタンを出す。スマホでは出さない |
| 補助のボタン列も塗りのある窓に入れる | 補助のボタン列は**枠線だけ**（「タイトルへ」ボタンと同じ見た目） |
| 左上に「タイトルへ」「音声」などを並べる | 左上は**一時停止ボタン1つ**にまとめ、中に「続ける・やりなおす・タイトルへ戻る・音声」 |
| 重要な数は画面に重ねて表示する（2D） | 重要な数は **3D 空間の中**に置く（半透明の立体の数字） |
| 起こり得ない選択肢は押せなくするか、そのまま | **薄く表示**する。ルール上は選べるので、押せるままにする |

## 8. 動き・タイミング

| 指示なしの場合 | こだわり |
|---|---|
| 浮いている物はゆらゆら揺らして生き生きさせる | 情報を示す物（中央の数字）は**揺らさない**。止まっていて読みやすいことを優先 |
| 演出（読み上げ）が終わってから結果を出す | **公平に感じられるタイミング**を優先：掛け声の「数」を言った瞬間に全員の手を出す（読み終わるのを待たない） |
| 大きく目立たせる | 中央の数字は**控えめ**（小さめ・透明度高め）。主役の手を邪魔しない |

---

## 使うときのメモ

- 新しく作るときは、この方針を前提にして、外れるところだけ確認してもらう。
- 数値（角丸・太さ・透明度など）は、ここに書いた値を最初の案にして、変えやすい形で作る。
