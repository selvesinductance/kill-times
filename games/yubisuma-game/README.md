# 一度親指を上げたら下げられない指スマ

3D の教室の中で、NPC（均衡戦略で打つ）と「一度上げた親指は下げられない」ルールの指スマを遊ぶブラウザゲームです。

## 動かし方

`fetch` と JavaScript のモジュールを使うので、ファイルを直接開くのではなく、手元でサーバーを立てて開きます。

```
cd このフォルダ
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

three.js r128 と Google Fonts はインターネットから読み込みます。

## ファイルの構成

```
index.html               画面の骨組み（タイトル・対戦・結果・各種の窓）
css/style.css            見た目（色・角丸・文字の太さ・画面幅ごとの配置）
js/main.js               起動: 3D の舞台 → 設定 → タイトル画面。データが届いたらボタンを押せるようにする
js/config.js             変わらない値（保存キー・掛け声・手の色・目安の確率）
js/settings.js           プレイヤーの設定（★・手の色・掛け声・音声）の保存
js/dom.js                画面の部品づくりと、日本語を文節の切れ目でだけ改行させる仕組み
js/voice.js              掛け声の読み上げ（合成音声）
js/game/rules.js         ゲームの決まり（手の数・固定の数・宣言の順番など。画面と切り離した部分）
js/game/strategy.js      NPC の戦略（均衡戦略 CSV の読み込み・出し方・下ろす手）と自動対戦
js/game/match.js         対戦の進行（掛け声 → 公開 → 判定 → 手を下ろす → 抜け）、操作、一時停止、結果
js/ui/title.js           タイトル画面（人数・番手のボタン、手の色、掛け声設定、ルール）
js/ui/screens.js         画面の切り替え
js/scene/stage.js        3D の土台（描画の準備・カメラ・光・共通の道具・トゥイーン）
js/scene/classroom.js    背景の教室
js/scene/meshing.js      形を作る計算（距離関数から面を作る・距離変換）
js/scene/glove-shape.js  手袋の形の計算と、計算済みデータの読み書き（three.js に依存しない）
js/scene/glove.js        手袋をはめた手（3D の部品）・親指の動き・輪郭
js/scene/seats.js        席（両手・名札・床の影）・宣言者の光の輪・自分の手の当たり判定
js/scene/counter.js      輪の中心に浮かぶ、立っている親指の数
js/scene/render.js       1 フレームの描画（ぼかした教室を敷き、手をくっきり重ねる）
js/scene/loop.js         画面の大きさに合わせたカメラ調整と、毎フレームの更新
data/yubisuma_eq_2p.csv  2 人戦の均衡戦略（3p・4p も同じ形式）
data/glove.txt           手袋の形（計算済み。base64 の文字列）
tools/gen-glove.mjs      手袋の形を計算し直して data/glove.txt を書き出す（node tools/gen-glove.mjs）
tools/simulate.mjs       NPC どうしの自動対戦で、1抜け率を均衡の値と比べる（node tools/simulate.mjs）
```

モジュールの依存は一方向です（main → ui / game → scene → stage）。対戦の状態（`match.js` の G）は他のモジュールから直接は触らず、`currentGame()` で読みます。

## 戦略 CSV の列

| 列 | 意味 |
|---|---|
| 人数 | その表を使う人数（誰かが抜けると、残りの人数の表に切り替わる） |
| 状態 | 宣言者から時計回りの各人の状態。例: 両2固1 = 手が 2 本残っていて、そのうち親指が固定された手が 1 本 |
| 位置 | 宣言者・次・2つ後・3つ後。「当てたら下がっている手を下ろす」の行は、当てたときに親指が下がっている手を下ろす場面 |
| 立てる本数 | 固定済みも含めて、立てている親指の合計 |
| 予想 | 宣言者だけ。自分以外の親指の合計の読み。宣言する数 = 立てる本数 + 予想。「外す」は場の手の数 + 1 を言ってわざと外す手 |
| 確率 | その出し方を選ぶ確率 |
| 望みなし | 1 位の望みが消えた NPC に 1（新しく親指を立てず、宣言は出せる範囲から一様に選ぶ） |
| 他の人の本数 | 「当てたら下がっている手を下ろす」の行だけ。他の人の立てる本数（次|2つ後|…） |

CSV は均衡の計算（別の研究用コード）から書き出したもので、このフォルダには計算用のコードは含みません。
